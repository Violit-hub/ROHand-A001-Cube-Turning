- Source: https://github.com/wuji-technology/wuji-mjlab
- Baseline commit: `b2b98d7054a8d1b0f5cf295d5acaebc4358bc6a9`
- Original project documentation: https://github.com/wuji-technology/wuji-mjlab/tree/b2b98d7054a8d1b0f5cf295d5acaebc4358bc6a9
- Original copyright, `LICENSE`, `NOTICE`, deployment sources and task documentation are preserved.
- Required Wuji description submodule: https://github.com/wuji-technology/wuji-description at `829c9aa27cb12c3a49d5b8d63c9869dd8f656702`.

The existing task identifier `WujiHand2_Reorient_50Hz` selects the adapted A001 hand in this repository. The retained Wuji hardware deployment tools do not implement A001 hardware control.
